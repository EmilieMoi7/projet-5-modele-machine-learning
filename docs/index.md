# Documentation — Projet 5 Machine Learning

Cette documentation décrit le fonctionnement, l’architecture et l’utilisation du projet **Projet 5 – Modèle de Machine Learning**, réalisé dans le cadre de la formation **AI Engineer**.

Elle s’adresse :
- aux développeurs souhaitant comprendre ou maintenir le projet,
- aux utilisateurs souhaitant utiliser l’application de prédiction,
- aux évaluateurs académiques.

## Contenu de la documentation

Cette documentation est organisée comme suit :

- **API** : description des entrées, sorties et du fonctionnement du pipeline de prédiction.
- **Modèle** : description du modèle de machine learning et de son intégration.
- **Performances** : informations générales sur les performances et les limites du modèle.
- **Tests & CI** : stratégie de tests unitaires et fonctionnels, intégration continue.
- **Déploiement** : instructions de déploiement local et via Docker.
- **Maintenance** : recommandations pour la maintenance et les évolutions futures.

## Contenu du projet

  Le projet vise à déployer un modèle de machine learning dans une application fonctionnelle, testée et documentée, intégrée dans un pipeline CI/CD.

Les objectifs principaux sont :
- garantir la fiabilité du pipeline de prédiction,
- automatiser les tests,
- documenter l’API et le modèle,
- fournir une base maintenable et évolutive.
